Files:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Privacy:
No student names are built into these files. The roster, attendance, session names and no-class reasons are stored locally in the browser on the device after use.

Hosting:
Upload all five files together to a static HTTPS host (for example GitHub Pages, Netlify, or Cloudflare Pages). Then open the HTTPS URL in Chrome on Android and choose Install app / Add to Home screen.

Backup:
Use “Backup App Data” inside the app regularly. Clearing browser/site data can erase locally stored records.
